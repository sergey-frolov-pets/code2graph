# radar

Series compared on shared axes. Aliases: radarchart, spider.

```
radar
title Платформы
axes Скорость, Надёжность, Безопасность
scale 0 --> 100
series А : 90, 92, 88
series Б : 78, 85, 94
```

`axes` needs at least three names. Each `series` has one number per axis.
