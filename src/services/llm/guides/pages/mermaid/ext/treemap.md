# treemap

Weights that fill a rectangle. Alias: tree-map.

```
treemap
title Бюджет
Инфраструктура / Облако : 420
Инфраструктура / Сеть : 180
Разработка / Бэкенд : 360
```

A row is `Group / Item : weight` with a positive weight.
