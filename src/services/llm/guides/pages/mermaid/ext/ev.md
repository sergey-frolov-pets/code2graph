# ev

Planned value, earned value, and actual cost. Alias: evchart.

```
ev
title Освоение
days 1, 2, 3, 4, 5
pv 10, 25, 45, 65, 90
ev 8, 20, 40, 58, 80
ac 12, 28, 50, 72, 95
```

`days`, `pv`, `ev`, and `ac` are required and must be the same length.
