vuePlantUML — ключи API для LLM (BYOK)

Ключ нужен только для провайдеров «свой ключ» в Настройки → AI. Бесплатные провайдеры без ключа работают через сервер приложения (POST /api/llm/chat).

Google Gemini google-gemini

Рекомендованный BYOK-провайдер. Модель по умолчанию: Gemini 2.0 Flash.

  1. Войдите в Google AI Studio.
  2. Создайте ключ: aistudio.google.com/apikey
  3. Free tier — лимиты Google (RPM / сутки). См. документацию.
  4. vuePlantUML: Настройки → AI → Google Gemini (свой ключ) → вставьте ключ.

Groq groq

Быстрые open-модели, free tier с лимитами RPM.

  1. Регистрация: console.groq.com
  2. Ключ: console.groq.com/keys
  3. Настройки → AI → Groq (свой ключ).

OpenRouter openrouter

Агрегатор моделей, доступны free-модели с суффиксом :free.

  1. openrouter.ai → аккаунт
  2. Ключ: openrouter.ai/keys
  3. Настройки → AI → OpenRouter (свой ключ).

Mistral mistral

  1. console.mistral.ai
  2. Ключ: API keys
  3. Настройки → AI → Mistral (свой ключ).

Безопасность

  1. Не коммитьте ключи в git и не публикуйте в issue.
  2. Ключ хранится только в localStorage вашего браузера.
  3. Не вставляйте ключ в share-URL диаграммы.

English — API keys for LLM (BYOK)

Keys are required only for “your key” providers in Settings → AI. Free providers without a key use the app server.

Google Gemini

  1. Create API key
  2. Paste in Settings → AI → Google Gemini (your key).

Same steps for Groq, OpenRouter, and Mistral — use each provider’s console.
