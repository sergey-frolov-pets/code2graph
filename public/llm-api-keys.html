vuePlantUML — ключи API для LLM

Выберите провайдера в Настройки → AI, создайте API-ключ на сайте провайдера и вставьте его в настройках.

Google Gemini google-gemini

Рекомендованный провайдер. Модель по умолчанию: Gemini 2.0 Flash.

  1. Войдите в Google AI Studio.
  2. Создайте ключ: aistudio.google.com/apikey
  3. vuePlantUML: Настройки → AI → Google Gemini → вставьте ключ.

Groq groq

  1. Регистрация: console.groq.com
  2. Ключ: console.groq.com/keys
  3. Настройки → AI → Groq.

OpenRouter openrouter

  1. openrouter.ai → аккаунт
  2. Ключ: openrouter.ai/keys
  3. Настройки → AI → OpenRouter.

Mistral mistral

  1. console.mistral.ai
  2. Ключ: API keys
  3. Настройки → AI → Mistral.

DeepSeek deepseek

Китайский LLM. Модель по умолчанию: deepseek-chat.

  1. platform.deepseek.com
  2. Ключ: platform.deepseek.com/api_keys
  3. Настройки → AI → DeepSeek.

Qwen (Alibaba) qwen

Китайский LLM от Alibaba. Модель по умолчанию: qwen-plus.

  1. DashScope Console
  2. Ключ: dashscope.console.aliyun.com/apiKey
  3. Настройки → AI → Qwen.

Zhipu GLM zhipu

Китайский LLM от Zhipu AI. Модель по умолчанию: glm-4-flash.

  1. open.bigmodel.cn
  2. Ключ: open.bigmodel.cn/usercenter/apikeys
  3. Настройки → AI → Zhipu GLM.

Moonshot (Kimi) moonshot

Китайский LLM от Moonshot AI. Модель по умолчанию: moonshot-v1-8k.

  1. platform.moonshot.cn
  2. Ключ: platform.moonshot.cn/console/api-keys
  3. Настройки → AI → Moonshot.

Безопасность

  1. Не коммитьте ключи в git и не публикуйте в issue.
  2. Ключ хранится только в localStorage вашего браузера.
  3. Не вставляйте ключ в share-URL диаграммы.

English — API keys for LLM

Choose a provider in Settings → AI, create an API key on the provider website, and paste it in Settings.
