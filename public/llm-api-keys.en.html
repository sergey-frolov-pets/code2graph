vuePlantUML — LLM API keys

Choose a provider in Settings → AI, create an API key on the provider website, and paste it in Settings.

Security of keys, passwords, and tokens

vuePlantUML does not send your secrets to third-party app servers. All sensitive data is stored only locally in your browser (localStorage) on your device:

  1. LLM API keys (Settings → AI) — only in your browser. The input field is cleared after save.
  2. Library server login and password (Settings → Library) — only in your browser. The password is not shown after save.
  3. Auth token for the library (after sign-in) — also stored locally and used only for requests to your server.

Recommendations:

  1. Do not commit keys, passwords, or tokens to git or publish them in issues.
  2. Do not put secrets in diagram share URLs or public chats.
  3. On a shared computer, remove credentials in Settings when you are done.
