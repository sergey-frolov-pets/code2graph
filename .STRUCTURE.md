# code2graph — структурный обзор проекта

> Сгенерировано 2026-11-16 из клона `sergey-frolov-pets/code2graph` (v1.2.65, 5ca4b5a9).
> Назначение: быстрая ориентация в кодовой базе без сканирования дерева файлов.

## Проект

- **Название:** Code2Graph
- **Сайт:** https://code2graph.ru
- **Автор:** Sergey Frolov (FSVibe), admin@code2graph.ru
- **Лицензия:** Prosperity Public License 3.0.0 (source-available; некоммерческое бесплатно, коммерческое — 30 дней триал, потом платно)
- **Стек:** Vue 3 + TypeScript + Vite (фронтенд), Node.js/Express (сервер), монорепа
- **Node:** >=20

## Возможности

- Редактор текстовых диаграмм: PlantUML, Mermaid, GraphML, WireMark, D2, Structurizr
- Живой предпросмотр, экспорт SVG/PNG
- Библиотека диаграмм (браузерная IndexedDB + REST-сервер)
- MCP-сервер для AI-агентов (Cursor и др.): отдаёт исходник + рендер
- AI-чат и правка выделения через LLM (свой ключ или прокси сервера)
- PWA, офлайн-редактирование
- Статический GitHub Pages + серверная версия (Docker Compose / VDSina)

## Архитектура монорепы

```
code2graph/
├── src/                    # Фронтенд (Vue 3 SPA)
├── server/                 # Бэкенд (Node.js, Express, SQLite)
├── packages/
│   ├── mcp/                # MCP-сервер для AI-агентов
│   └── shared/             # Общий код фронтенд↔MCP (agent-diagram, llm-pages, d2-source, structurizr-source)
├── apps/
│   └── billing-admin/      # Админка биллинга (Vue, отдельный Vite-билд)
├── sandbox/                # Тестовый стенд для диаграмм (фикстуры .mmd + golden-рендеры SVG)
├── scripts/                # Сборка, деплой, утилиты (.mjs/.sh)
├── public/                 # Статика: иконки, манифест, PlantUML-библиотеки (C4, ArchiMate)
├── docs/                   # Документация (деплой, биллинг, LLM, Mermaid-расширения)
└── deploy/                 # Конфиги деплоя (systemd-юнит, server.env)
```

## Ключевые архитектурные решения

1. **Монорепа** — фронтенд, сервер, MCP и общий код в одном репо
2. **Локальный рендеринг** — PlantUML и Mermaid рендерятся в браузере (без внешних API)
3. **IndexedDB** — основное хранилище диаграмм на клиенте
4. **Серверная библиотека** — опционально, через REST API (SQLite)
5. **LLM-прокси** — сервер может проксировать запросы к LLM, скрывая ключи
6. **MCP-интеграция** — отдельный пакет, запускается как sidecar-процесс
7. **PWA** — офлайн-режим, установка на устройство
8. **Один HTML-файл** — релиз собирается в `code2graph.html` (все ресурсы инлайн)
