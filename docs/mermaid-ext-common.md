# Mermaid Ext — общий SVG-слой

Утилиты, общие для всех движков. Без DOM: ни `document`, ни `getBBox`,
ни `canvas.measureText` — иначе рендер не заработает в тестах и в SSR.

## 1. Измерение текста без DOM

`measureText(text, fontSize, weight)` → `{ width, height }`.

Таблица ширин по глифам в единицах `em` (доля от `font-size`), для
`font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.

- Латиница строчная ≈ `0.52`, заглавная ≈ `0.66`, цифры ≈ `0.56`.
- Кириллица строчная ≈ `0.54`, заглавная ≈ `0.68` (шире латиницы).
- Пробел `0.28`, точка/запятая `0.28`, `%` `0.86`, `₽` `0.62`.
- Неизвестный глиф — `0.58` (среднее).
- `height = fontSize * 1.2`, базовая линия `fontSize * 0.8`.

Точность ±8% — достаточно: приоритет читаемость, не пиксель-в-пиксель.
Все подписи дополнительно **обрезаются** по `maxWidth` с добавлением `…`.

## 3. Сборка SVG

`createSvg({ width, height, palette, debugFrames })` → объект-строитель.

- Корень: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H"
  role="img" font-family="system-ui, ...">`. **Без** `width`/`height`.
- `<title>` — заголовок диаграммы, если задан (доступность).
- Все элементы — через методы строителя, чтобы экранирование было
  в одном месте: `esc()` для текста и атрибутов.
- Числа форматируются до 2 знаков, без хвостовых нулей (`12.5`, `40`).
- `debugFrames: true` → каждому элементу добавляется
  `data-debug="<id>"` и `stroke="#ff00aa" stroke-width="0.5"`.

## 4. Общее

- `esc(s)` — `& < > " '`.
- `fmt(n)` — число → строка.
- `clamp(v, min, max)`.
- `niceTicks(min, max, count)` — «круглые» деления оси (1/2/5 × 10ⁿ).
- `truncate(text, maxWidth, fontSize)` — обрезка с `…`.
- `arrowMarker(svg, color, id)` — маркер-стрелка для orgchart.

## 5. Инварианты (проверяются тестами)

1. Ни один движок не импортирует `document`, `window`, `canvas`.
2. В SVG нет `http://` / `https://` вне `xmlns`, нет `<script>`, нет `@`.
3. Корневой `<svg>` не имеет атрибутов `width`/`height`.
4. Все тексты проходят через `esc()`.
