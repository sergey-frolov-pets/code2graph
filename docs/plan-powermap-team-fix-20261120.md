## Шаг 1. Причина красного теста (A) — 1 файл, S

**Файл:** `src/services/mermaid/ext/engines/powermap.ts`, `routeInfluences()`.

**Причина.** После перехода на общий `layoutTeamGroups` карточки сместились (убран лишний `insetX` по Y),
а препятствия для маршрута влияния по-прежнему строятся через `cardsBetween(from, to)` — только карточки
внутри прямоугольника между концами. Маршрут с командной обвязкой уходит за пределы этого прямоугольника
(обход рамки), и вертикальный сегмент попадает в карточку, которой в `cardsBetween` нет.

**Правка (минимальная).** Для hit-теста и обхода брать `cards.filter(c => c.id !== from && c.id !== to)`,
а не `cardsBetween(...)`; `cardsBetween` оставить только как быстрый предфильтр для `routeAroundCards`.

**Проверка:** `npx vitest run src/services/mermaid/ext/__tests__/powermap.test.ts` (должно быть зелёным),
затем `npm run golden:update` и глазами `65-powermap-team-basic`.

**Риск:** маршруты без команд станут строже к карточкам → возможны сдвиги в старых golden.
Смягчение: включать новый набор препятствий только когда `model.teams.length > 0`.
